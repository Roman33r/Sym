# Город вместе

Градостроительный симулятор в браузере на несколько человек: участки земли, жеребьёвка, уровни поселения, дороги, ЛЭП, водопровод, автобусы, зоны, рынок и потребности жителей.

## Играть без сервера

Откройте https://roman33r.github.io/Sym/ (или просто `index.html`).

1. Один игрок нажимает «Создать игру (я хост)». Город считается и сохраняется в его браузере — вкладку не закрывать.
2. Хост нажимает «Пригласить игрока» и отправляет другу код приглашения.
3. Друг нажимает «Подключиться к игре», вставляет код и отправляет хосту код ответа.
4. Хост вставляет код ответа — игроки соединяются напрямую (WebRTC). Для каждого следующего игрока — новое приглашение.

## Играть через свой сервер

Нужен [Node.js](https://nodejs.org), зависимостей нет.

```bash
node server.js
```

Откройте http://localhost:3000; остальные игроки в сети заходят по адресу, который напечатает сервер. Город сохраняется в `city.json`.
